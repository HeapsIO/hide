# HIDE

## Architecture

- HIDE runs on Electron. The main process is Haxe code (`hide_js/hide/ElectronMain.hx`, built into `bin/main.js` by the second part of `hide.hxml` (after `--next`)); the renderer is `bin/app.html` + `bin/hide.js`.
- Renderer code talks to the main process only through the wrappers in `hide_js/libs/electron/` (`electron.Ipc`, `electron.Window`, `electron.Clipboard`, ...). Main process externs are in `hide_js/libs/electron/main/`.
- Keep main process code in Haxe, not hand-written JS.
- `haxe hide.hxml` builds both `bin/hide.js` (WebGL) and `bin/main.js`; `haxe hide_jsdx.hxml` the same with DX12; `haxe hide_hl.hxml` the HashLink editor. The shared libraries / defines / includes are in `hide_common.hxml`. The Electron runtime is unpacked in `bin/electron/`.
- DirectX 12 (jsdx) : `haxe hide_jsdx.hxml` builds `bin/hide.js` with the heaps DX12Driver (heaps branch `js-dx12`). The HL emulation (`hlemu`) and `dx` API are in `hide_js/libs`; the N-API addon `bin/jsdx/dx12.node` is built by `npm run build` in `hide_js/libs/jsdx` (`native/build.bat`, needs Visual Studio with the C++ tools, and the hashlink sources from `HASHLINK_SRC` or the `hashlink` haxelib). After modifying its C++ sources (`hide_js/libs/jsdx/native`), rebuild `dx12.node` (close HIDE first : the loaded addon blocks the link). It also has the heaps natives of HashLink (`libs/heaps` : mikktspace, meshoptimizer, V-HACD, compiled unmodified), used by `hide.tools.NativeMeshTools` (the HL code of `hxd.tools.MeshTools`) with DX12 instead of the meshTools executable. When loaded, the addon disables the power throttling (EcoQoS) of the page thread, which Windows otherwise puts on the efficiency cores when HIDE is not in the foreground. `dx/Dx12.hx` is generated by `hide_js/libs/jsdx/native/gen-dx12-hx.js`, do not edit it. 64 bits values (`hl.I64` = `hlemu.I64`, `haxe.Int64`, `dx.Address`) are `haxe.Int64` : passed to the addon as two int32 arguments (low, high), returned as BigInt (`napi_prim.h`, `hlemu.Macros.makeNativeCall`) — GPU descriptor handles are above 2^53. CPU pointers (`hl.Bytes`) stay JS numbers (`mem_get_ptr` / `mem_set_ptr`).
- DX12 with several scenes : one `h3d.Engine` per scene (as with WebGL, `multidriver`), all sharing a single `DX12Driver` (`DX12Driver.inst`, never disposed : compiled shaders / pipelines are kept). Each `Scene` renders into its own texture (the driver's default depth buffer takes the scene's depth resource and size while rendering), and its engine is resized with the canvas without resizing the shared driver. `dx.Display` copies that texture into a texture of the canvas shared with Chromium (two per canvas, recreated only when the size changes) and draws it with WebGPU after the present. The driver's emulated swapchain is not displayed. `DX12Driver` itself is unchanged. The addon has one swapchain per command queue and shares its D3D12 device between the pages of the renderer process (main window, thumbnail generator).

## Running the editor for tests

- When launching HIDE yourself to test something, ALWAYS set `HIDE_TEST=1`. In this mode:
  - `alert` / `confirm` / `prompt` popups are replaced by console logs (`bin/test-preload.js`), so no blocking exception popup is shown to the user;
  - it implies `--background` : windows are shown without activation and never focused / maximized, so they stay in the background behind the user's windows, and Chromium throttling is disabled so the page keeps rendering.
- Unset `ELECTRON_RUN_AS_NODE` (set by VSCode), and use `--enable-logging=stderr` to get the renderer console in the output. Use your own `--user-data-dir` (the app is single instance per user data dir), `--default-config` to ignore the user's configs and `--project-dir=<dir>` to pick the project:
  `cd bin && env -u ELECTRON_RUN_AS_NODE HIDE_TEST=1 ./electron/electron.exe --enable-logging=stderr --remote-debugging-port=9223 --user-data-dir=<temp dir> --default-config --project-dir=<dir> . > log.txt 2>&1`
- With `--remote-debugging-port`, expressions can be evaluated in the page through the DevTools protocol (`http://127.0.0.1:9223/json/list` then `Runtime.evaluate`), e.g. `hide.Ide.inst.views.length`.
- Resize the window to at least 1600x900 (`hide.Ide.inst.window.resizeTo(1600, 1000)`) : the default one leaves no width to scene views.
- Kill only your own instance before relaunching, never all `electron.exe` : the user's hide may be running.
